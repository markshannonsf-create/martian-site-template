# The Martian Creative site template

The starting point for a client website. Every site begins as a copy of this
and diverges only where the client actually needs something different — which
is the whole point: the fifth site is cheaper than the first because most of it
was already built and already works.

```
npm install
npm run dev        # http://localhost:4321
npm run build
npm run deploy
```

## The contract

**One file decides what the site says: `site.config.json`.** A build that needs
a page edited to change a phone number is a build that will have the wrong
phone number.

It has two halves, and the difference matters:

| Key | What it is | Edited by hand? |
|---|---|---|
| `site` | What actually renders — name, brand, nav, sections, contact | **Yes.** This is the site. |
| `brief` | The client's intake answers, generated from the panel | **No.** Regenerated by `newsite`; it is the source material, not the content. |

The brief is there so the answers are at hand while building — what they asked
for, what they said to avoid, where their email is hosted. Nothing in it is
rendered. If something in it is wrong, fix it in the panel, because the signed
agreement quotes those answers.

### `site`

```jsonc
{
  "name": "Sergeant Prints",          // shown in the header and the title
  "tagline": "Short line under it",   // optional
  "domain": "sergeantprints.com",     // canonical host, used for absolute URLs
  "description": "…",                 // the meta description, ~155 characters
  "brand": {
    "accent": "#c2410c",              // one color; everything else derives
    "font": "system"                  // "system" or a Google font family name
  },
  "nav": [{ "label": "Work", "href": "#work" }],
  "sections": [ … ],                  // the home page, in order
  "contact": {
    "phone": "…", "email": "…",
    "address": "…", "hours": "…",
    "blurb": "…"
  },
  "legal": { "privacy": true, "terms": true }
}
```

Anything set to `null` or left out is not rendered. There is no placeholder
copy anywhere in this template on purpose — a site that ships with "Lorem
ipsum" ships with "Lorem ipsum".

### Sections

The home page is a list of blocks. Five types cover most of what a local
business needs; add a sixth when a client genuinely needs one, and add it
**here** rather than in their repo.

| `type` | Fields | For |
|---|---|---|
| `hero` | `heading`, `text`, `cta: {label, href}`, `image` | The top of the page |
| `text` | `id`, `heading`, `body` (paragraphs) | Anything prose |
| `cards` | `id`, `heading`, `items: [{title, text, href}]` | Services, categories |
| `gallery` | `id`, `heading`, `images: [{src, alt}]` | Work, products, the room |
| `cta` | `heading`, `text`, `cta: {label, href}` | Asking for the call |

## What is already handled

- **Responsive** without a framework, and readable at 320px.
- **Light and dark**, following the visitor's setting. The accent is the only
  color to choose; the rest derives from it.
- **SEO**: title, description, canonical, Open Graph, JSON-LD `LocalBusiness`,
  `sitemap.xml`, `robots.txt`.
- **Accessible**: real landmarks, a skip link, visible focus, and contrast
  checked against the accent rather than assumed.
- **Fast**: no client JavaScript at all unless a section needs it. Nothing to
  hydrate, nothing to block rendering.
- **Legal pages** at `/privacy` and `/terms`, written for a client site rather
  than copied from a SaaS.

## Deploying

`wrangler.jsonc` carries the Worker name. `newsite` fills it in from the panel;
if you are doing it by hand, replace `__SLUG__` everywhere.

```
npm run deploy
```

Then put the deploy hook into the panel under **Where the sites live**, so the
site can be redeployed without opening a terminal, and so there is a written
answer to "their site is down, what do I look at".

## Improving it

**Improvements come back here.** A fix made only in a client's repo has been
given away — every other client keeps the bug, and the template is the asset.
When something is worth having twice, it belongs in this repo and gets pulled
forward into the sites that want it.
